# Pi Borderless Tables

把普通 assistant 表格显示为无框对齐表：列间两个空格，表头下面用分段粗横线 `━`，数据行之间用细横线 `─`，不画外框或竖线。表头文字加粗，颜色跟随 Pi 主题。只改变显示，不改写会话原文或模型上下文，不调用模型。

## 安装

随[仓库 Git package](../../README.md#安装)安装，入口为 `packages/pi-borderless-tables/index.ts`。可用 `pi config` 单独停用；更新和卸载方式见仓库说明。

无需额外配置，不改变 Mermaid、chart 或代码块扩展的设置。加载或停用后 `/reload` 或重开。

## 使用

例如屏幕显示：

```text
项目  状态    说明
━━━━  ━━━━━━  ━━━━━━━━━━━━━━━━━━━━━━━━━━
API   完成    鉴权接口通过测试，准备预发布
────  ──────  ──────────────────────────
UI    进行中  检查移动端布局和键盘操作
```

列对齐遵循 Markdown：`---` / `:---` 左对齐，`:---:` 居中，`---:` 右对齐。数值列也只按标记处理，不会自动对齐或按增减上色；重点数据可用 `**加粗**`。

源消息仍是标准 Markdown 表格。使用 Pi 原生 `/copy` 可复制最近一条助手回复的原文，不会混入本扩展生成的显示框线、ANSI 或行编码；首尾空白沿用 Pi 原生处理。该命令复制整条回复，不是只复制一张表；手动选择屏幕文字则得到当前显示文本。扩展不监听或自动写入剪贴板。

## 边界

- 支持流式及完成态 assistant 回复，不必等整条回复结束。表头结构成型后即应用样式；流式消息的末行可暂缺后续列，继续输入时保持无框显示。user、thinking 不变。
- 所有正常内容宽度均使用相同样式；resize 按当下宽度重排，不转成卡片。长文本由 Pi 原生表格布局换行，换行内部不加分隔线，末行后不画底边。
- 复用公开 `Markdown` 的布局、行内格式、数学、宽字符和链接处理，再按列位置去掉结构框线。表头强调及可用终端中的超链接保留；内容自身的 `│` 等字符不会被全局删除。
- 仅处理 Marked 识别的顶层表格，至少一列；完成态至少一行数据，流式期间可仅有表头。外侧 `|` 可省略；除流式消息末尾的数据行外，表头、分隔行及其他数据行列数必须一致。空表头和空值保留。
- 流式末行只允许将尚未输入的列显示为空，不截掉多余内容；Pi 会去掉消息末尾的空白，扩展无法区分末行是否已换行。后面出现其他行或块、或停止生成后，恢复完整校验。其他缺列、多列、转义 pipe 或控制字符等无法无损确认的表格保留原文；CRLF 等 lexer 规范化导致原文不一致时，整条回复保持原文。
- 不转换嵌套表格，不改普通正文、代码、Mermaid 或 chart，也不改变相邻缩进代码、列表或段落。表格中的引用链接复用全消息的定义（包括引用块内的定义）。
- 按[开发基线](../../docs/development.md#兼容基线)中的 Pi 原生表格布局识别；框线结构变化或极窄宽度无法识别时回退原生显示，不保证所有异常或超窄表格都去框。

## 开发

通用命令见[开发指南](../../docs/development.md#验证)。彩色渲染测试可在本包目录补充运行：

```sh
FORCE_COLOR=3 bun run test
```

测试通过公开 `registerMarkdownTransformer`、真实 Pi `Markdown` 和 `AssistantMessageComponent`，覆盖 40/80/120 列、双向 resize、表头粗线与数据行细线、左右及居中对齐、中英 emoji、空值、行内格式/空格/标点/转义的渲染等价、内容中的框线字符、可点击链接、错列回退、相邻块边界、Mermaid/chart 混排、逐字符流式输入时样式稳定且单元格内容保留、宿主去除末尾空白、结束态一致、消息类型、dark/light。

未在本包测试中启动真实模型、fullscreen 会话，或验证其他扩展的加载顺序与所有导出路径。
