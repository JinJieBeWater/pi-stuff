# Pi Borderless Tables

把普通 assistant 表格显示为无框对齐表：列间两个空格，只保留表头分隔线，不画外框、竖线或行间横线。只改变显示，不改写会话原文或模型上下文，不调用模型。

## 启用

需要 Pi `1.4.0` 或更新版本；当前只验证了 `1.4.0`。在仓库根目录运行：

```sh
bun install --frozen-lockfile
pi install ./packages/pi-borderless-tables
```

已有会话执行 `/reload`。停用时在仓库根目录运行 `pi remove ./packages/pi-borderless-tables`，再 `/reload`。不需要额外配置，不改变现有 Mermaid、chart 或代码块扩展的设置。

## 显示与复制

例如屏幕显示：

```text
项目  状态    说明
────  ──────  ──────────────────────────
API   完成    鉴权接口通过测试，准备预发布
UI    进行中  检查移动端布局和键盘操作
```

源消息仍是标准 Markdown 表格。使用 Pi 原生 `/copy` 可复制最近一条助手回复的原文，不会混入本扩展生成的显示框线、ANSI 或行编码；首尾空白沿用 Pi 原生处理。该命令复制整条回复，不是只复制一张表；手动选择屏幕文字则得到当前显示文本。扩展不监听或自动写入剪贴板。

## 转换边界

- 只处理完成态 assistant 回复。user、thinking 和 streaming 逐字透传；完成后才切换为无框表。
- 所有正常内容宽度均使用相同样式；resize 按当下宽度重排，不转成卡片。长文本由 Pi 原生表格布局换行。
- 复用公开 `Markdown` 的布局、行内格式、数学、宽字符和链接处理，再按列位置去掉结构框线。表头强调及可用终端中的超链接保留；内容自身的 `│` 等字符不会被全局删除。
- 仅处理 Marked 识别的完整顶层表格，至少一列、一行数据。外侧 `|` 可省略；表头、分隔行和数据行列数必须一致。空表头和空值保留。
- 缺列、多列、转义 pipe 或控制字符等无法无损确认的表格保留原文；不依赖 Marked 补齐或截掉单元格来“修复”输入。CRLF 等 lexer 规范化导致原文不一致时，整条回复保持原文。
- 不转换嵌套表格，不改普通正文、代码、Mermaid 或 chart，也不改变相邻缩进代码、列表或段落。表格中的引用链接复用全消息的定义（包括引用块内的定义）。
- 按 Pi `1.4.0` 的原生表格框线布局识别；框线结构变化或极窄宽度无法识别时回退原生显示，而非冒险删字符。因此不保证异常/超窄表格都去框。

## 验证

开发依赖由仓库根目录的 Bun workspace 安装提供，仅用于测试和类型检查。在本 package 目录运行：

```sh
bun test
FORCE_COLOR=3 bun test
bun run check-types
```

测试通过公开 `registerMarkdownTransformer` 和真实 Pi `Markdown`，覆盖 40/80/120 列、双向 resize、单一表头分隔线、中英 emoji、空值、行内格式/空格/标点/转义的渲染等价、内容中的框线字符、可点击链接、错列回退、相邻块边界、Mermaid/chart 混排、流式与消息类型、dark/light。

未在本包测试中启动真实模型、fullscreen 会话，或验证其他扩展的加载顺序与所有导出路径。
