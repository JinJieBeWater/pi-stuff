# Pi Tool Groups

每次工具调用显示成一行概览：工具做了什么、成功与否、用了多久。中间没有文字隔开的调用合并成一块，排成一张表：工具名一列对齐，同一工具连续调用时只写一次。内容（输出、diff、文件内容）等你点开再看，正在运行的调用显示一段预览，结束后立刻折叠；点开才显示完整内容。只改变显示，不改写会话、工具结果或模型上下文。任何工具都能用，不需要适配。

```text
▸ 1 earlier
bash      $ git status --short                               0.1s
read      …/pi-tool-groups/README.md                         0.0s
bash      $ git clone https://example.com/repo.git         ✗ 0.0s
          $ cd …/server && make                              1.9s
          $ cd …/client && make test                         4.2s
codemode  const p = "…/index.ts"; await tools.edit(…         1.4s
```

每块只显示最近 5 条。失败（时长前的 `✗`）和运行中（还没有时长，整块换成运行中的底色）的调用不会折叠，也不会把整块染红；成功不标。概览里的路径统一写法：当前目录写成 `.`，家目录写成 `~`；相邻几行共有的长路径再缩成 `…/`。工具名一列至少 8 个字符宽，所以常用工具的块之间也对齐。

## 安装

随[仓库 Git package](../../README.md#安装)安装，入口为 `packages/pi-tool-groups/index.ts`。可用 `pi config` 单独停用；更新和卸载方式见仓库说明。无需配置。加载或停用后 `/reload` 或重开。

只想试用时，在新窗口运行：

```sh
pi -e ~/my/pi-stuff/packages/pi-tool-groups/index.ts
```

## 使用

全屏模式下点哪里就改变哪里，运行中也可以：

| 点击          | 效果                   |
| ------------- | ---------------------- |
| 某一行        | 打开或收起这一条的内容 |
| `▸ N earlier` | 显示或收起更早的调用   |

点开的那一条比命令再缩进一层，显示全部内容，不截断：完整的命令或脚本、完整的输出，`write` 的文件和 `edit` 的 diff。正在运行、自动展开的调用只显示输出的最后几行，结束后收起。`Ctrl+O` 照常显示每条调用的完整内容，单独一条调用恢复 Pi 原本的样子，并清掉之前的点击状态。

## 分组规则

连续的调用合并成一块，不分工具。下面这些会把块断开：

- 非空的 thinking 或文本
- 用户消息、`!` 命令、可见的自定义消息、压缩和分支摘要
- 因长度截断的消息；没有工具调用的中止或报错消息
- 结果带图片的调用，它单独成行，图片留在原位

## 边界

- 分组边界依据会话内容计算，看不到扩展自绘的条目、缓存未命中提示和临时状态行。一组可能跨过它们显示，内容不丢，只是位置靠前。
- 尚未注册的工具保持原样。结果带图片的调用也保持原样，因为图片画在渲染器之外，收不起来。
- 普通模式没有鼠标，内容只能用 `Ctrl+O` 看，所以这个扩展更适合全屏模式。
- 折叠状态不跨重启保存。codemode 内部的调用仍显示在其父调用内。
- HTML 导出不分组。
- 不要和同样修改工具显示的 `@tian.zuo/pi-compact-output` 一起使用。
