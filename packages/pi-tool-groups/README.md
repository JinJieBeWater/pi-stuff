# Pi Tool Groups

每次工具调用显示成一行概览：工具做了什么、成功与否、用了多久。中间没有文字隔开的调用合并成一块，排成一张表：工具名一列对齐，同一工具连续调用时只写一次；连续的 `read`、`grep`、`find`、`ls` 再合成一行，比如 `read 3 · grep 1`。内容（输出、diff、文件内容）等你点开再看，正在运行的调用在下面显示最新的 3 行，一轮结束时折叠；点开才显示完整内容。只改变显示，不改写会话、工具结果或模型上下文。任何工具都能用，不需要适配。

```text
▸ 8 more · bash 6, read 2
▎read 3 · grep 1                                             0.2s
▎bash      $ git clone https://example.com/repo.git        ✗ 0.0s
▎          $ cd …/server && make                             1.9s
▎          $ cd …/client && make test                        4.2s
▎codemode  const p = "…/index.ts"; await tools.edit(…        1.4s
```

每块只显示最近 10 条（合成一行的读和搜索算一条），更早的收成一行，写明是哪些调用，比如 `▸ 8 more · bash 6, read 2`。失败（时长前的 `✗`）和运行中（还没有时长）的调用不会折叠。块没有底色，只有你的消息带底色；每条调用左边一条竖线标出状态：完成绿、失败红、运行中是主题强调色。竖线占 Pi 原本留白的那一列，所以工具名和你的消息、模型的文字从同一列开始。概览里的路径统一写法：当前目录写成 `.`，家目录写成 `~`；相邻几行共有的长路径再缩成 `…/`，运行中的调用不参与，免得它一出现就改动旁边的行。工具名一列至少 8 个字符宽，所以常用工具的块之间也对齐。

## 安装

随[仓库 Git package](../../README.md#安装)安装，入口为 `packages/pi-tool-groups/index.ts`。可用 `pi config` 单独停用；更新和卸载方式见仓库说明。无需配置。加载或停用后 `/reload` 或重开。

只想试用时，在新窗口运行：

```sh
pi -e ~/my/pi-stuff/packages/pi-tool-groups/index.ts
```

## 使用

全屏模式下点哪里就改变哪里，运行中也可以：

| 点击              | 效果                       |
| ----------------- | -------------------------- |
| 某一行            | 显示完整内容，再点收起     |
| 打开的内容        | 收起这一条                 |
| `read 3 · grep 1` | 逐条显示或收起这些读和搜索 |
| `▸ N more`        | 显示或收起更早的调用       |

点开的那一条比命令再缩进一层，显示全部内容，不截断：完整的命令或脚本、完整的输出，`write` 的文件和 `edit` 的 diff。正在运行的调用自动显示最新的 3 行：有输出时是输出的末尾，还没有输出时是模型正在写的参数的末尾。输出保留工具自己的配色，参数是纯文本；每行只占一行，过长的截断而不折行。这片区域固定 3 行高；合成一行的读和搜索收起时，里面正在运行或刚结束的那条也照样显示这 3 行，所以一条读加入时对话不会变矮。结束后停在最终输出的最后 3 行；模型接着 thinking 或写文字时不动，下一条调用出现时才收起，新调用接手这 3 行；一次并行发出的几条调用一起保留、一起收起。所以一轮进行中对话只会变长，只在这一轮结束（或你发消息）时收起一次。`Ctrl+O` 照常显示每条调用的完整内容，单独一条调用恢复 Pi 原本的样子，并清掉之前的点击状态。

## 分组规则

连续的调用合并成一块，不分工具。下面这些会把块断开：

- 非空的 thinking 或文本
- 用户消息、`!` 命令、可见的自定义消息、压缩和分支摘要
- 因长度截断的消息；没有工具调用的中止或报错消息
- 结果带图片的调用，它单独成一块，图片紧跟在它那一行下面

## 边界

- 分组边界依据会话内容计算，看不到扩展自绘的条目、缓存未命中提示和临时状态行。一组可能跨过它们显示，内容不丢，只是位置靠前。
- 尚未注册的工具保持原样。调用的图片画在渲染器之外，所以总显示在它那一行下面，收不起来。
- 普通模式没有鼠标，内容只能用 `Ctrl+O` 看，所以这个扩展更适合全屏模式。
- 折叠状态不跨重启保存。codemode 内部的调用仍显示在其父调用内。
- HTML 导出不分组。
- 不要和同样修改工具显示的 `@tian.zuo/pi-compact-output` 一起使用。
